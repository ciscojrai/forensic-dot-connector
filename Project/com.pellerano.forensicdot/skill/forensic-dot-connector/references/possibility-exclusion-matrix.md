# Possibility and Exclusion Matrix

The Possibility and Exclusion Matrix defines the standardized output structure for forensic analysis reports generated by Forensic Dot Connector.

## Matrix Structure

Every generated report must format findings using the following schema:

```markdown
# Forensic Mining Dossier: [Photo Identifier]

## 1. Verified Evidence Inventory
- Metadata: [Timestamp / Camera / Dimensions / Resolution]
- Environmental Clues: [Decor, Fixtures, Architecture, Season]
- Personal Item Clues: [Attire, Jewelry, Watches, Eyewear]
- Technology Clues: [Identified Electronics, Form Factors, Displays]
- Text & OCR Artifacts: [Transcribed Signage, Labels, Headings]

## 2. Chronological Bounds Analysis
| Indicator Item | Observed State | Historical Release Window | Lower Bound ($T_{min}$) | Upper Bound ($T_{max}$) | Confidence |
|---|---|---|---|---|---|
| [Identified Tech/Object] | [Features] | [e.g. 2004–2008] | [e.g. 2004] | [e.g. 2012] | High |

## 3. Possibilities (Estimated Timeline Range)
- Most Probable Window: [e.g. 2005 – 2008]
- Supporting Corroboration: [Summary of converging clue vectors]

## 4. Definite Exclusions (Impossible Eras)
- Excluded Era 1: Pre-[Year] (Reason: Presence of [Identified Object] released in [Year])
- Excluded Era 2: Post-[Year] (Reason: Physical absence of later infrastructure/obsolete formats)

## 5. Narrative Historical Synthesis
[Objective narrative synthesizing the scene, individuals, objects, and provenance without speculative fiction.]
```

## Field Rules
- Missing or non-visible clues must be marked `Not Visible`.
- Date bounds must cite the specific historical release anchor.
